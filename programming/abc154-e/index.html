  • 競プロ

NNN の上 iii 桁をつなげた数を N(i)N(i)N(i) とする。 NNN の上から iii 桁目を NiN_iNi​ とする。NNN の桁数を lll とする。

dp[i,k,0]={n∈Z∣n<N(i), n の 0 でない数字の数が k}dp[i,k,0] = \{ n \in \mathbb{Z} \mid n < N(i) ,\ n \text{ の } 0 \text{ でない数字の数が } k \}dp[i,k,0]={n∈Z∣n<N(i), n の 0 でない数字の数が k} dp[i,k,1]={n∈Z∣n=N(i), n の 0 でない数字の数が k}dp[i,k,1] = \{ n \in \mathbb{Z} \mid n = N(i) ,\ n \text{ の } 0 \text{ でない数字の数が } k \}dp[i,k,1]={n∈Z∣n=N(i), n の 0 でない数字の数が k} とすると、求めたいのは dp[l,K,0]+dp[l,K,1]dp[l,K,0] + dp[l,K,1]dp[l,K,0]+dp[l,K,1] である。

dp[i,0,0]=1,dp[i,0,0]=1, dp[i,0,0]=1, (0 に対応)

dp[1,1,0]=N1−1,dp[1,1,0] = N_1-1,dp[1,1,0]=N1​−1, (1,…,N1- 1に対応)

dp[1,k,0]=0(k≥2),dp[1,k,0]= 0 (k \ge 2),dp[1,k,0]=0(k≥2),

dp[1,k,1]=1,dp[1,k,1] = 1,dp[1,k,1]=1,
