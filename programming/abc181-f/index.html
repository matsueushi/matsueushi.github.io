AtCoder ABC 181 F - Silver Woods

2022年08月20日 プログラミング
  • AtCoder
  • 競プロ

https://atcoder.jp/contests/abc181/tasks/abc181_f

rrr を動かした時に、動かす円の中心が存在できない範囲を考えてみる。 壁もしくは障害物から距離 rrr 未満の位置に円の中心を配置することができないことを考えると、動かせない範囲は下の青色で示した領域の内部になる。

上の壁と下の壁が図で示した青色の領域を通じて繋がっていなければ円が通過でき、繋がっていれば円が通過できない。 繋がっているか繋がっていないかはUnionFindで判定できる。

  • y=100y=100y=100 と 釘 (xi,yi)(x_i, y_i)(xi​,yi​) が繋がっている <=> yi+2r>100y_i + 2 r > 100yi​+2r>100
  • y=−100y=-100y=−100 と 釘 (xi,yi)(x_i, y_i)(xi​,yi​) が繋がっている <=> yi−2r<100y_i - 2 r < 100yi​−2r<100
  • 釘 (xi,yi)(x_i, y_i)(xi​,yi​) と 釘 (xj,yj)(x_j, y_j)(xj​,yj​) が繋がっている <=> (xi−xj)2+(yi−yj)2<(2r)2(x_i-x_j)^2 + (y_i-y_j)^2 < (2r)^2(xi​−xj​)2+(yi​−yj​)2<(2r)2

これで rrr が与えられたときの判定方法がわかったので、あとは rrr を二分探索する。
